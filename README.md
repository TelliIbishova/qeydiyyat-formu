
# Qeydiyyat Formu

React və Vite istifadə edilərək hazırlanmış qeydiyyat formu.

## Xüsusiyyətlər

- Ad, email və şifrə inputları
- Cins seçimi
- Maraq dairələrinin seçilməsi
- Şəhər seçimi
- Qeyd sahəsi
- Form validation
- Uğurlu göndərilmə mesajı

## Layihəni işə salmaq

```bash
npm install
npm run dev
```
